# Security Policy

## Supported versions

Security fixes are currently provided for the latest TrainerBridge 1.0.x release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting page:

https://github.com/adventureFAN/TrainerBridge/security/advisories/new

Do not publish exploitable details in a public issue before a fix is available.

TrainerBridge launches third-party trainer executables selected by the user. A malicious or unsafe trainer is not itself a TrainerBridge vulnerability. Never attach trainer executables, game files, complete Proton prefixes, save files, or personal data to a report.
